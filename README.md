# Controle de Peças

Aplicativo para celular que acompanha as peças de um evento: lista do coordenador, conferência de saída, retorno com quebras e perdas, e reposição.

Protótipo v0.1. Os dados ficam no próprio aparelho.

## Desenvolvimento

```
pnpm install
pnpm dev
pnpm build
```

`pnpm seed` regenera `src/data/seed.ts` a partir das planilhas em `../contexto/planilha`.
